# Security and Operational Notes

- The evidence is retained for reproducibility.
- No passwords, tokens, private keys, or credentials should be published.
- Publication should be checked for unnecessary IP addresses, MAC addresses, hostnames, local workstation paths, and other environment-specific identifiers.
- The existing laboratory identity has privileged USS characteristics, so this part must not be used as evidence of ordinary-user access-control behavior.
- RC 8 is an intentionally selected application-level test value.
