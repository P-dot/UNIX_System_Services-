# References

Primary product/documentation references used to frame the lab:

- IBM Redbooks, *z/OS Version 1 Release 11 Implementation* (SG24-7729-00). Relevant because the laboratory runs z/OS 1.11 and the publication covers z/OS UNIX and zFS within that release context.
- IBM Redpaper, *z/OS UNIX Security Fundamentals* (2007). Covers the UNIX security model, z/OS UNIX implementation, users/groups, permissions, HFS/zFS and BPXPRM-related security considerations.
- IBM, *z/OS Security Server RACF Security Administrator's Guide*, z/OS V1R11 edition. Used for RACF concepts and OMVS user/group integration.
- IBM, *z/OS Basic Skills Information Center: Security on z/OS*. Includes security for z/OS UNIX.

The screenshots in this lab are the authoritative evidence for the specific ADCD system state. Documentation is used for terminology and conceptual interpretation; release-specific runtime claims come from the captured environment.
