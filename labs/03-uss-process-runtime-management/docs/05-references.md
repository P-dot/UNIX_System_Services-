# 05 — References

Primary evidence for this lab is the captured behavior of the user's z/OS USS environment.

Useful IBM documentation families for the concepts exercised here:

- IBM z/OS UNIX System Services Command Reference — `ps`, `kill`, `sleep` and related USS commands.
- IBM z/OS UNIX System Services User's Guide — shell execution, processes and job-control concepts.
- IBM z/OS UNIX System Services Programming: Assembler Callable Services Reference — process and signal concepts at the USS services layer.

Because command availability and output can vary by z/OS release and shell implementation, the documented terminal evidence is treated as authoritative for this laboratory environment.
